# Security policy

## Reporting a problem

Open an issue or a pull request{{DISCUSSIONS_CLAUSE}} and I'll take a look.

You can also report privately: open the repository's **Security** tab and choose **Report a vulnerability**. A confirmed problem is fixed in a new release, and the advisory is published once the fix is on nuget.org. Affected versions are then marked deprecated on nuget.org with the fixed version as the alternate.

This is a one-person project with no bug bounty and no response deadline. I'll reply when I can and say what I plan to do.

## Supported versions

Only the latest major version ({{MAJOR}}.x) gets security fixes.
